# AIORI-3-HACKATHON-PROJECTS
This repository will contain the code and resources for the AIORI-3 hackathon that will be developed during the AIORI-3     
NetFix    
AIORI-3 Hackathon Project  
About the Project: Home and last-mile internet connectivity diagnosis  
About the Project:   
NetFix is a solution designed to help users identify, understand and diagnose home internet connectivity issues through an explainable approach.
